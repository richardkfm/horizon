# Radio and mesh network setup

A radio or mesh network only helps if it's set up, powered, and tested before
it's needed. Use this list when you start, then go through the "keep it
working" section every month. The background is in
[[technology-two-way-radio]] and [[technology-mesh-network]].

> **Tip:** Check your country's rules before you transmit — licence-free
> radio has power and antenna limits, and amateur (ham) radio needs a licence.

## Two-way radio

- [ ] Tier chosen (licence-free handhelds, CB, or licensed amateur radio)
- [ ] Local rules checked; licence obtained if needed
- [ ] Enough radios for each household or key person
- [ ] A main channel and a backup channel agreed and written down
- [ ] A simple call plan: who calls in, when, and in what order
- [ ] An antenna raised as high as practical for the base station
- [ ] Outdoor connections weatherproofed
- [ ] Everyone shown how to use them: listen first, keep it short, plain
      language

## Mesh messaging

- [ ] A mesh messaging app installed on willing neighbours' phones and
      tested over several hops
- [ ] LoRa mesh nodes flashed with open mesh firmware, if using them
- [ ] Nodes placed for more than one path, not a single chain
- [ ] Failure tested: one node switched off, messages still get through
- [ ] A shared channel name and settings written down for new members

## Power

- [ ] Rechargeable batteries for every handheld, plus a spare set
- [ ] Chargers that work from solar, a 12 V battery, or pedal power
- [ ] Mesh nodes on small solar panels or batteries
- [ ] Power banks kept at about half charge in storage (see
      [[energy-everyday-batteries]])

## Paper backup

- [ ] Channel plan, call order, and frequencies printed and laminated
- [ ] Contact list with call signs or names per radio
- [ ] A log book and pencil at the base station

## Keep it working (monthly)

- [ ] A scheduled check-in call on every radio
- [ ] A test message across the mesh
- [ ] Batteries charged and rotated
- [ ] Antennas and cables checked for damage
- [ ] New members shown how to use the system
